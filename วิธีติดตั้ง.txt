PAT Smart Check — กราฟวงแหวนวอร์รูม

ติดตั้ง
1. อัปโหลด warroom.html และ warroom.js ไปแทนไฟล์ชื่อเดิมใน GitHub pat-smart-check-portal (ระดับเดียวกับ teacher.html)
2. รอ GitHub Actions สีเขียว แล้วรีเฟรช warroom.html (คอมพิวเตอร์ใช้ Ctrl+F5)
3. ไม่ต้องแก้ Apps Script หรือ Deploy ใหม่

สิ่งที่เปลี่ยน
- กราฟภาพรวมตามศูนย์ ห้อง และวันที่ที่เลือก
- กราฟแยกรายศูนย์ ใช้เขียว=ตรงเวลา ส้ม=สาย แดง=ถึงเวลาแล้วแต่ยังไม่เช็คอิน
- เปอร์เซ็นต์รวมผู้เช็คอินแล้วทั้งตรงเวลาและสาย หารด้วยผู้ถึงเวลาเริ่มกะ
- วันหยุด ลาที่อนุมัติ และผู้ยังไม่ถึงเวลาเริ่มกะไม่นับในฐานเปอร์เซ็นต์
- กรณีไม่มีผู้ถึงเวลาเริ่มกะแสดงวงสีเทาและขีด แทน 0%
- ใช้รอบโหลดและอัปเดตอัตโนมัติเดิม ไม่มีคำขอข้อมูลเพิ่ม
- ดูรายชื่อห้องได้จากปุ่มดูห้องเรียนของศูนย์นี้ตามเดิม รายการสีข้างกราฟเป็นคำอธิบาย ไม่ใช่ปุ่มกรอง

ตรวจแล้ว
ทดสอบจำนวนแต่ละส่วน เปอร์เซ็นต์ กรณีไม่มีข้อมูล สายทั้งหมด เข้างานครบ และยังไม่เช็คอินทั้งหมด ผ่าน รวมถึงตรวจโครงสร้าง HTML และไวยากรณ์ JavaScript
ยังไม่ได้ติดตั้งบนเว็บจริงหรือยืนยันภาพในเบราว์เซอร์มือถือจริง หลังติดตั้งให้เทียบตัวเลขกับข้อมูลเดิมและลองจอมือถือ
