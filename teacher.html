PAT SMART CHECK · พื้นที่ครู

ตารางกะส่วนกลาง

เข้าสู่ระบบด้วยบัญชี Google ที่ผู้ดูแลกำหนดสิทธิ์ไว้

เข้าสู่ระบบครู

รองรับบัญชี Google ของหน่วยงานและ Gmail ส่วนตัว ตรวจอีเมลกับสิทธิ์ประจำศูนย์ก่อนแสดงรายชื่อนักเรียน

เปิดหน้าลงชื่อเข้าใช้ Google

ระบบจะพาไปลงชื่อเข้าใช้ Google ในแท็บนี้ เมื่อลงชื่อเข้าใช้เสร็จ กดปุ่มเข้าสู่พื้นที่ครู เซสชันมีอายุไม่เกินหนึ่งชั่วโมง

ทะเบียนนักเรียน จัดการรอบฝึกจัดการสาขาวอร์รูม / ตรวจลงเวลา

จัดการสิทธิ์ครู

Super Admin ดูแลทุกศูนย์ อีเมลครูทั่วไปใช้ได้เฉพาะศูนย์ที่กำหนด

เพิ่มหรือแก้ไขสิทธิ์

เลือกศูนย์ที่รับผิดชอบ หากไม่เลือกเลยจะปิดสิทธิ์ครูทุกศูนย์ของอีเมลนี้

บทบาท Super Admin

ใช้กับอีเมลด้านบน ให้สิทธิ์จัดการทุกศูนย์และเปลี่ยนสิทธิ์ผู้อื่น

ประวัติแก้สิทธิ์ล่าสุด 50 รายการ

คำขอและการอนุมัติ

กะเดิมจะเปลี่ยนหลังครูอนุมัติ

ตรวจคำขอได้ทุกวันที่นักเรียนส่ง ไม่ต้องเลือกวันที่ในวอร์รูม

รับรองชั่วโมงฝึก

สำหรับฝึกรอบพิเศษและพาร์ตไทม์

ยังไม่เปิดบันทึกจริง — รอกำหนดเกณฑ์เวลาพัก การนับชั่วโมง และการรับรองบางส่วน ชั่วโมงพาร์ตไทม์ยังไม่รวมเป็นชั่วโมงฝึกอัตโนมัติ

คำขอผูกบัญชี LINE

ตรวจเจ้าของบัญชีกับตัวนักเรียนก่อนอนุมัติ แสดงเฉพาะศูนย์ที่คุณรับผิดชอบ

เลือกนักเรียนแล้วกดยกเลิกการผูก LINE ได้ที่นี่

ระบบกรองรายชื่อตามการมอบหมายร้าน วันที่สีเทาอยู่นอกช่วงฝึกหรือช่วงมอบหมายร้าน

0 นักเรียน
0 กะและวันหยุด
0 ยังไม่จัดกะ

คลิกช่องวันที่เพื่อแก้กะ หรือดาวน์โหลดต้นแบบกรอกทั้งเดือนแล้วนำเข้า ช่องว่างในไฟล์ไม่ลบกะเดิม ต้องยืนยันกะนักเรียนจึงจะเห็นใน LINE
